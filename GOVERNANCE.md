## Maintainer authority

Official project maintainers decide whether a proposed contribution is merged into the official MAESTRO repository.

This is distinct from MAESTRO's internal runtime Councils.

GitHub project governance governs the repository.

MAESTRO Councils govern the architecture and runtime concepts implemented by MAESTRO.

## Architectural changes

Changes to any of the following should receive explicit review:

- constitutional principles;
- Council authority;
- EX/AY separation;
- security blockers;
- TX durable state;
- model authority boundaries;
- state machine;
- governed adaptation;
- governed activation;
- transaction integrity;
- Local Gateway trust boundary.

## Releases

Official releases should identify:

- version;
- source commit;
- test status;
- migration notes where needed;
- known limitations.
