# Dynamic Council Architecture

The original 18 APTE Councils are the **Genesis Councils**.

```text
CAPABILITY GAP
→ COUNCIL PROPOSAL
→ AY STRUCTURAL REVIEW
→ SHADOW
→ EVALS
→ EX AUTHORIZATION
→ HUMAN GOVERNANCE APPROVAL (v0.3)
→ INSTALLED
```

A new skill is not automatically a new Council. Create a new Council only when a genuinely new jurisdiction/authority is required.

Dynamic capsules are stored as compressed content-addressed objects and loaded lazily.
