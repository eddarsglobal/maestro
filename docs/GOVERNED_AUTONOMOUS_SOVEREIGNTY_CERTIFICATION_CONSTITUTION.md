# MAESTRO Governed Autonomous Sovereignty Certification Constitution

## Scope

ASC0.1 governs:

- BM2-031 Autonomous Loop
- BM2-032 Sovereignty Certification

ASC0.1 is the final BordingMap 2.0 composition boundary.

## ASC-01 — Mission contract remains the root

Every downstream autonomous artifact SHALL preserve the governed mission
contract lineage.

AUTONOMY != OBJECTIVE DRIFT.

MISSION EXECUTION != MISSION REDEFINITION.

## ASC-02 — The autonomous loop is Council-native

Capability demand SHALL resolve through governed Council ownership.

Execution routes SHALL bind responsible Councils.

Council execution remains downstream of governed routing and EX evidence.

COUNCIL ROUTED != COUNCIL SOVEREIGN.

COUNCIL EXECUTION != COUNCIL AUTHORITY EXPANSION.

## ASC-03 — Resource selection preserves sovereignty

Capability contracts SHALL remain provider-, model- and runtime-independent.

Concrete provider/model/runtime identities remain resource metadata.

RESOURCE SELECTED != RESOURCE AUTHORITY.

MODEL SELECTED != MODEL AUTHORITY.

PROVIDER SELECTED != PROVIDER AUTHORITY.

## ASC-04 — Planning and execution remain separated

Plan validation MAY establish execution eligibility.

Execution eligibility SHALL NOT itself authorize execution.

PLAN VALIDATED != EXECUTION AUTHORIZED.

EXECUTION_ELIGIBLE != EXECUTION_AUTHORIZED.

ROUTING PLAN != EXECUTION.

## ASC-05 — Execution produces evidence, not truth

Council execution SHALL produce explicit route-bound execution witnesses.

EXECUTED != VERIFIED.

OUTPUT != EVIDENCE CLOSURE.

EXECUTION SUCCESS != SYSTEM TRUTH.

## ASC-06 — Evidence closure precedes mission verdict

Node closure SHALL preserve exact plan, route, Council, capability and
resource lineage.

EXECUTION COMPLETE != EVIDENCE COMPLETE.

EVIDENCE COMPLETE != MISSION ACCEPTED.

MISSION ACCEPTED != SYSTEM TRUTH.

## ASC-07 — Autonomous operation remains recoverable

Durable mission state SHALL retain governed recovery information.

Recovery remains evidence-bound and fail-closed.

FAILURE != AUTHORITY EXPANSION.

RECOVERY != OBJECTIVE DRIFT.

RECOVERY READY != RECOVERY EXECUTED.

## ASC-08 — Durable experience remains downstream

Immutable experience SHALL bind the durable checkpoint, mission contract,
plan, routing and mission verdict.

EXPERIENCE != LEARNING AUTHORITY.

LEARNING != PROMOTION.

MISSION HISTORY != POLICY AUTHORITY.

## ASC-09 — Full autonomous operation preserves sovereignty

The complete autonomous loop SHALL remain:

- provider-independent
- model-independent
- runtime-independent
- Council-governed
- evidence-bound
- fail-closed
- recoverable
- zero-model compatible

MAESTRO COMMANDS MODELS.

MODELS DO NOT COMMAND MAESTRO.

ZERO MODEL != ZERO GOVERNANCE.

AUTONOMY != AUTHORITY.

## ASC-10 — Completion is not production release authority

BordingMap 2.0 completion SHALL NOT itself:

- authorize a production release
- move a production release tag
- activate a provider
- activate a model
- expand Council authority
- assert system truth

PROJECT_COMPLETE != RELEASE AUTHORIZED.

CERTIFIED != RELEASED.

MISSION SUCCESS != SYSTEM TRUTH.
