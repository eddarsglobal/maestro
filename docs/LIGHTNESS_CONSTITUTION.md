# MAESTRO Lightness Constitution

- **APTE-LIGHT-01** Nothing heavy remains resident without governance necessity.
- Prefer references over copies.
- Prefer immutable shared base context plus overlays over duplicated contexts.
- Cold experience stays outside the active working set.
- Learning increases knowledge density, not runtime mass.
- Integrations are optional adapters, not Core dependencies.
- Core mass, resident Councils, context bytes and working evidence are measurable.
- A feature that exceeds Mass Budget must justify itself or be externalized/lazy-loaded.

> MAESTRO SHALL SCALE BY ADDING REACH, NOT MASS.
