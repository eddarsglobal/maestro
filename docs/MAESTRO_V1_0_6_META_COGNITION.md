# MAESTRO v1.0.6 — META-COGNITION

## Purpose

MAESTRO now evaluates whether its current operational understanding is good enough to continue.

It does not inspect hidden thoughts.

It evaluates observable signals:

```text
EVIDENCE
CONTRADICTIONS
ASSUMPTIONS
RETRIES
PROGRESS
RESOURCE CALLS
LATENCY
COST
CAPABILITY GAPS
HUMAN APPROVAL REQUIREMENTS
```

## Meta loop

```text
MISSION STATE
   ↓
META SIGNALS
   ↓
CONFIDENCE / EVIDENCE / DRIFT
   ↓
META ASSESSMENT
   ↓
CONTINUE
REQUEST MORE EVIDENCE
CHANGE STRATEGY
DEEPEN COGNITION
REDUCE COGNITION
REVALIDATE ASSUMPTIONS
ESCALATE AY / EX
REQUEST HUMAN APPROVAL
BLOCK
```

## Important

Meta-cognition never becomes a 19th Council.

It cannot:
- waive SC or JR;
- grant tool permissions;
- authorize TX commit;
- approve irreversible actions;
- change the Constitution;
- self-authorize new powers.

## Calibration

After verified outcomes, MAESTRO can compare predicted confidence to actual verified quality.

This allows detection of systematic overconfidence without storing private reasoning traces.
