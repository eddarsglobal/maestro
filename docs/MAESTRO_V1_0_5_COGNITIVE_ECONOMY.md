# MAESTRO v1.0.5 — COGNITIVE ECONOMY

## Purpose

Decide how much intelligence a mission deserves.

MAESTRO now distinguishes:

```text
TRIVIAL
LOW
MEDIUM
HIGH
CRITICAL
```

and maps those to governed spend envelopes:

```text
MINIMAL
STANDARD
DEEP
MAX_GOVERNED
```

## Spend dimensions

- maximum cognitive stages;
- maximum resource calls;
- maximum candidates per stage;
- max tokens per call;
- total token ceiling;
- latency ceiling;
- cost ceiling;
- critic requirement;
- verifier requirement;
- multi-resource permission.

## Marginal utility

Before deeper cognition, MAESTRO may compare:

```text
EXPECTED QUALITY GAIN
+ EXPECTED EVIDENCE GAIN
--------------------------------
TOKENS + LATENCY + COST
```

If marginal utility is too low, MAESTRO stops.

## Important

Economy never overrides:
- hard security;
- legal/compliance;
- evidence requirements;
- human approval;
- AY SYSTEM validation;
- EX/TX durable commit sequence.

## Lightness

A complex mission is allowed to become cognitively large temporarily.
MAESTRO itself remains small and releases temporary cognitive mass after execution.
