# MAESTRO v1.0.4 — COGNITIVE FABRIC

## Purpose

Compose multiple intelligence resources inside one mission without allowing them to become a collective sovereign.

## Typical code path

```text
MAESTRO
  ↓
COGNITIVE PLAN
  ↓
SCOUT
  ↓
PRODUCER
  ↓
CRITIC
  ↓
VERIFIER
  ↓
STRUCTURED ARTIFACTS
  ↓
EVIDENCE / AY / EX / TX
```

## Important distinction

The Cognitive Fabric is not a chatroom of models.

Models do not autonomously converse.

MAESTRO:
- builds each stage contract;
- decides which upstream artifacts are visible;
- chooses the resource;
- limits output/context mass;
- records the result;
- decides whether the next stage may run.

## Roles

- SCOUT: low-cost orientation / constraints.
- PRODUCER: primary generation or solution.
- CRITIC: challenge the producer output.
- VERIFIER: structural/evidence-oriented check.
- SYNTHESIZER: optional bounded synthesis.

These are cognitive functions, not Councils.

## Lightness

The fabric is bounded by:
- max stages;
- max resource calls;
- max parallel candidates;
- max total output mass.

The normal state remains minimal.


## Market exploration boundary

Cognitive Fabric production execution uses the best measured eligible resource by default.
Market exploration is disabled unless explicitly enabled. New/under-tested resources should normally be exercised through Academy or shadow evaluation before receiving production work.
