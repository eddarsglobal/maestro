# Local Provider Constitution

## LP-01
A local model is a replaceable intelligence resource, not a Council authority.

## LP-02
Provider availability must not alter APTE constitutional authority.

## LP-03
Discovery is runtime-driven; model names are not hardcoded into the Constitution.

## LP-04
Private/thinking fields are transient by default and are not Learning Memory.

## LP-05
Raw model context token arrays are not durable memory by default.

## LP-06
Academy may benchmark local models and propose routing changes.

## LP-07
Adaptive policy may select among eligible models but may not expand permissions or Council authority.

## LP-08
Embeddings are memory indexes, not truth.

## LP-09
The smallest sufficient model is the default bootstrap preference.

## LP-10
Cloud providers remain optional; local-first must not become provider lock-in.
