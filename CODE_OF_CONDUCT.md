# MAESTRO Community Code of Conduct

The MAESTRO community exists to build serious engineering work collaboratively.

We expect contributors to:

- communicate professionally;
- critique ideas and code rather than people;
- provide evidence for technical claims when practical;
- acknowledge uncertainty;
- respect different backgrounds and levels of experience;
- avoid harassment, threats and discriminatory conduct;
- avoid deliberately deceptive technical behavior;
- respect security disclosure rules;
- respect licensing and authorship.

Maintainers may moderate discussions, Issues, pull requests or participation when conduct materially harms the project or its contributors.
